# Kivo 新版 Web 控制台

本文对应 v0.2.8 开发版。页面随 Go 程序嵌入，不需要 Node.js、数据库、CDN 或前端构建环境。

## 设计原则

采用轻量的专业工作台布局：固定侧栏、单一主操作、统一卡片与表单、中性底色及克制的靛蓝强调色。亮暗主题共享组件与间距；已有主题偏好继续保留，新会话默认亮色。

界面不显示没有数据来源的流量曲线、在线率或“已加速”指标。主机状态、最近检测和当前选择分别表述，避免看起来成功但实际没有接入。

所有状态表示运行 Kivo 的主机和用户，而不是远程打开网页的设备。

## 推荐使用流程

1. 在“内核管理”安装 Mihomo。下载时，全局进度区显示阶段、已下载大小、已知总量、速度和失败原因。
2. 在“订阅管理”添加来源。订阅文件下载默认直连；加密来源可选 AES 或 AGE，认证来源可选 Basic / Bearer / Token。
3. 选择批量下载路径并更新订阅。结果面板显示各来源的节点数、更新前数量、耗时与失败原因。
4. 在“代理节点”选择出口。内核运行后可选择真实节点；离线缓存不能直接选用。
5. 在“网络概览”点击“连接代理”。它会启动内核、接入主机系统代理，并按复选框选项检测外网。
6. 同时确认总览结论和三步状态链，不要只看内核运行或节点延迟。
7. 不再使用时点击“断开代理”，恢复连接前的系统代理设置。

安装、接入及其他需要确认的操作仍会先说明风险；控制台不会替用户无声覆盖其他代理软件的配置。

## 如何看状态

| 区域 | 回答的问题 | 正常含义 |
| --- | --- | --- |
| 代理服务 | 内核与本地代理端口是否就绪？ | 运行中 · 端口就绪 |
| 系统接入 | 主机系统代理是否指向本程序？ | 已自动接入；手动接入单独标识“未接管” |
| 外网检测 | 最近两分钟内的代理入口与节点出口是否通过？ | 代理路径检测通过 |
| 当前出口 | PROXY 策略组实际使用哪个节点？ | 显示运行时实际节点，而不是静态配置的推测 |
| 连接健康度 | 直连、本地代理入口、节点出口分别怎样？ | 三条路径独立显示状态和探测明细 |

“服务已启动”不等于“浏览器已接入”。“系统已接入”不等于“节点能上网”。节点测速通过也不等于所有网站都可访问。

直连对照失败不必然影响代理路径。刷新状态不会主动检测外网；超过两分钟、内核停止、检测时间无效或后台失联时，旧成功结果失效。后台失联表示状态未知，不代表代理进程必然已停止。

## 各页面

### 网络概览

顶部为连接结论和连接 / 断开主操作，右侧显示实际出口与本地 HTTP / SOCKS5 地址。下方依次是三步状态链、连接健康度和运行摘要。

“系统接入与高级控制”默认收起，包含仅接入、保留内核恢复系统代理、异常备份恢复、仅内核生命周期及进程 / 端口 / TUN 明细。强制恢复仍需额外确认。

### 代理节点

- 同时按关键词、订阅与检查状态筛选。
- 默认顺序、延迟优先、名称排序；延迟优先将未通过和离线缓存排在检查通过的节点后面。
- 每页显示 24 个节点；翻页后回到列表顶部。
- “检查通过”只来自最近一次测试，不用节点总量暗示在线量。
- 没有节点或没有匹配结果时，提供管理订阅 / 清除筛选的入口。

### 订阅管理

批量下载路径与“更新全部 / 检查全部”位于单独操作区。分组管理默认折叠，提供独占启用、按组操作及新建分组。独占使用会停用其他组与组外订阅，需要确认。

每个来源拥有独立路径选择、启停、更新、检查及删除操作。路径选择遵循现有 API：更新偏好可能被保存到订阅，不是只对本次请求生效。

持久结果面板显示每项成功 / 失败、节点数量及耗时；未知数量显示“未确认”，不会编造成 0。订阅下载路径只影响拉取文件，节点健康检查始终通过各节点进行。

添加弹窗区分必填项与高级周期 / 前缀选项。Esc 关闭、Tab / Shift+Tab 在可见控件间循环，关闭后回到原按钮。提交进行中不能意外关闭或重复提交。

### 内核管理

分为当前引擎与本地版本。提供启动 / 重启 / 停止、安装最新版、切换非活动版本与确认删除。安装进度跨页面可见。

这里的启动仅管理内核。希望浏览器自动接入时，应在概览点击“连接代理”。

### 路由策略

内置配置使用中文标签，明确默认代理 / 直连动作与当前策略。配置卡片、规则编辑器与规则组列表分开呈现。

规则从上到下匹配；添加后重载运行中的内核，删除需要确认。通过 CLI 创建的自定义策略仍按原名称显示。

### 环境诊断

汇总检查项目总数、通过数与需要关注的数量；逐项显示名称、状态和建议。失败时明确显示“诊断未完成”，不沿用旧通过结论。

环境诊断不修改系统配置，也不替代外网检测。

### 运行日志

查看最近 300 条输出；支持文本筛选、复制当前显示内容、导出本地日志文件。导出不会向第三方上传数据。

自动刷新只在已登录、页面可见且当前处于日志页时执行。阅读旧日志时不会被新输出强制拉到底部。日志同步失败保留旧内容但标记同步失败。

### 偏好设置

分别配置网络 / 下载、流量接管、控制台安全。读取网络设置失败时禁用保存；未保存时切换页面或刷新会询问是否丢弃修改。该页面不编辑 Web 监听地址，保存不会写入临时的 `serve --listen` 覆盖值。

Web Token 修改仍立即生效，输入留空保存代表关闭鉴权，并非保持原 Token。当前开启鉴权时，关闭前会再次确认。不要把控制台无鉴权暴露到不可信网络。

## 交互与维护约束

- 页面宽度自适应；手机使用抽屉导航与遮罩，关闭时导航不进入键盘焦点序列。
- 长节点、域名与路径允许换行；节点和内核表格的必要横向滚动限制在表格内部。
- 状态颜色同时配文字，不单靠颜色传达成功或失败。
- SVG 图标内置，装饰图标不进入辅助技术阅读序列。
- 减少动态效果的系统偏好会禁用非必要动画。
- 忙碌按钮恢复原图标和禁用状态；表单请求有重复提交保护。
- 动态内容使用 `textContent`；订阅名、节点名与日志不能被解释为 HTML。
- 样式令牌集中在 `app.css`，API 事务、状态判断、渲染及事件绑定在 `app.js` 分离为函数，不引入额外框架。

## 本次验证范围

- `node --test scripts/test-web.mjs`：覆盖原安装流、安全状态与新增分页、排序、旧结果失效、按钮恢复、文本注入及 DOM 契约。
- Go 全量测试、静态检查及六个平台交叉构建。
- 使用 computer-use 浏览器验收八个页面、亮暗主题、1440px 桌面与 390px 窄屏布局。
- 独立虚拟接口提供 218 个演示节点，验证筛选、排序、分页、选点、直连 / 代理批量订阅结果、诊断及日志筛选。
- 使用重新编译程序及独立数据目录验证真实后端的默认配置与空状态。

演示接口不发出真实代理请求；本次没有改动用户现有订阅、凭据、系统代理或 TUN。此验收不等同于重新完成真实节点联网测试，也不等同于 macOS / Linux 实机验证。

## 更新到新版页面

Web 资源已嵌入可执行文件，修改源码后仅刷新旧进程不会生效。

1. 保存当前操作，在旧 CLI 执行 `/shutdown` 完整退出。它会断开代理、关闭内核与 Web，请选择合适时机。
2. 启动新编译的 `kivo` / `kivo.exe`。默认沿用当前数据目录，不需要重建订阅。
3. 打开原控制台地址；必要时用 Ctrl+F5 强制刷新。

本地开发版与已发布 v0.2.7 分开放置。本次改版不会自动推送仓库或改写远程 Release。

完成本地提交和产物整理后，可直接运行 `dist/kivo.exe`；六个平台的最新安装包在
`dist/latest/`，版本快照保留在 `dist/releases/`。程序的 `version` 输出包含对应源码提交哈希。
